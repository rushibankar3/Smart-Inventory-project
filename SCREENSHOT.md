# Screenshots

## Web Interface Screenshot

This screenshot shows the Smart Inventory AI web interface in action.

### Description:
- The interface displays a title "Smart Inventory AI"
- An input field for entering the product category
- A button labeled "Check Inventory Status"
- After clicking, it shows:
  - Predicted Demand for the next period
  - Current Inventory Level
  - Status: UNDERSTOCK, OVERSTOCK, or OK
  - Recommended Action (e.g., "Reorder X units" or "Inventory optimal")

### How to take the screenshot:
1. Run the application as described in the README
2. Open the Streamlit app at http://localhost:8501
3. Enter a category like "Groceries"
4. Click "Check Inventory Status"
5. Take a screenshot of the browser window

The actual screenshot image should be named `screenshot.png` and placed in the root directory of the project.
